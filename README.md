# Yarn Price Calculator

A simple, browser-based tool for comparing yarn prices by calculating the cost per 100g. This helps crafters find the best value when purchasing yarn.

## Features

- Calculate and compare yarn prices based on weight and cost
- Automatically identifies the best value yarn in your comparison
- Shows relative value compared to the cheapest option
- Export your comparison data to CSV
- Save and load your yarn data using save codes
- No installation required - works entirely in your browser

## How to Use

1. Enter the yarn name, price, weight, and quantity
2. Click "Calculate Price per 100g" to add it to your comparison
3. Add multiple yarns to compare their values
4. The cheapest yarn (per 100g) will be highlighted in green
5. Use the "Export to CSV" button to download your comparison data
6. Use the "Data Management" tab to save your data for future use

## Data Management

Since the app runs entirely in your browser and doesn't use a server, your data is not automatically saved. To save your data:

1. Go to the "Data Management" tab
2. Click "Generate Save Code"
3. Copy the code and save it somewhere safe (like a text file)
4. When you return later, paste the code and click "Load Save Code"
