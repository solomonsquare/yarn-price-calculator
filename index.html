Data Management

Since browser storage isn't available, you can save your data by copying the code below and pasting it back later:

Instructions for saving your data:

  1. Click "Generate Save Code" to create a code containing all your yarn data
  2. Copy the code and save it somewhere safe (like a text file or note app)
  3. When you return later, paste the code in the box and click "Load Save Code"

Tips for Using the Calculator:

1. Use the "Export to CSV" button to download your data for use in spreadsheet applications.

2. You can delete individual yarns from your comparison using the delete buttons.

3. To save your data for future use, go to the "Data Management" tab.
